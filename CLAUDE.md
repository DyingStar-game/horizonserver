# CLAUDE.md — horizonserver

Conventions for anyone (human or AI) changing this repository. Keep this file short: rules that hold
for every change, not the state of a feature.

## Pull requests

- The `CHANGELOG_EN` / `CHANGELOG_FR` blocks of a PR description follow the skill
  `changelog-entry` (types, areas, wording); the PR check "Check Changelog Entry" enforces it.
